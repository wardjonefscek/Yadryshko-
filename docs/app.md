# Cad+ — программа расчёта крыла и нервюр

Cad+ считает консоль крыла и лонжероны, затем облегчает нервюры топооптимизацией и выдаёт их контуры в DXF для ЧПУ или SVG для просмотра. Стартовый проект — самолёт из сводки параметров от 05.11.2026: трапециевидное крыло 1000 мм, Clark Y, трубка Ø10×1, нервюры из СТЭФ 2 мм.

> Результаты — расчётная оценка. Они не подтверждают лётную годность и не заменяют статические испытания крыла и соединителя. Свойства материалов по умолчанию справочные и помечены «не проверено». DXF не отправлять в резку без проверки.

## Установка на Windows 10/11

1. **Rust.** Скачайте `rustup-init.exe` с [rustup.rs](https://rustup.rs) и запустите. Установщик предложит поставить Visual Studio Build Tools (компоненты C++) — согласитесь, без них Rust на Windows не собирает программы. Нужную версию Rust (1.97.0) rustup скачает сам при первой сборке.
2. **Код.** В терминале:
   ```
   git clone https://github.com/wardjonefscek/Yadryshko-.git
   cd Yadryshko-
   ```
3. **Сборка и ярлык.** Из папки репозитория:
   ```
   powershell -ExecutionPolicy Bypass -File scripts\install-windows.ps1
   ```
   Первая сборка занимает 5–10 минут. Скрипт кладёт `cadplus.exe` в `%LOCALAPPDATA%\Cad+` и создаёт ярлык **Cad+** на рабочем столе.
4. Без ярлыка программу можно запустить так: `cargo run --release -p cadplus-gui`.

Если окно не открывается (старая видеокарта), запустите с переменной `CADPLUS_RENDERER=glow`. В PowerShell: `$env:CADPLUS_RENDERER="glow"; cargo run --release -p cadplus-gui`.

На Linux достаточно `cargo run --release -p cadplus-gui`.

## Где лежат файлы

| Что | Где |
|---|---|
| Проект | `Документы\Cad+\проект.cadplus.json` (путь можно сменить в верхней строке) |
| Экспорт | папка `export` рядом с файлом проекта: `нервюры.dxf`, `нервюры.svg` |

Проект — открытый JSON. В нём все исходные данные, библиотека материалов и координаты профиля.

## Как работать

1. **Крыло** — размах, хорды, поперечное V, профиль. Профиль загружается из файла `.dat` (форматы Selig и Lednicer), по умолчанию — Clark Y из базы UIUC.
2. **Расчётный случай** — полётная масса, перегрузка n, коэффициент безопасности f, схема распределения.
3. **Лонжероны** — сечение (трубка, рейка, коробка), материал, участок по размаху, положение по хорде, признак «соединитель консолей», статус «кандидат».
4. **Нервюры** — шаг, толщина, материал, минимальная стенка у лонжерона.
5. **Изготовление и оптимизация** — ЧПУ (диаметр фрезы, поле станка) или FDM (сопло, стол), посадка отверстий, кромка, кольца, доля материала, минимальная перемычка.
6. Кнопка **«Оптимизировать все нервюры»**. Расчёт идёт в фоне, окно не зависает, его можно остановить. Ход расчёта виден на вкладке нервюры.
7. **«Экспорт DXF + SVG»**.

Горячие клавиши: Ctrl+Z — отменить (до 200 шагов), Ctrl+Y — повторить, Ctrl+S — сохранить.

Ключи запуска: путь к файлу проекта; `--rib N` — открыть нервюру N; `--ribs` — таблица нервюр; `--optimize` — сразу оптимизировать все нервюры.

### Слои DXF

| Слой | Что | В CAM |
|---|---|---|
| CONTOUR | Наружный контур нервюры | резать по внешней стороне |
| HOLES | Отверстия под лонжероны (окружности, с посадкой) | резать по внутренней стороне |
| POCKETS | Облегчающие вырезы | резать по внутренней стороне |
| LABELS | Подписи «R1 z0 x2»: номер, станция, количество | **не резать** |

Нервюры раскладываются столбцами с зазором 5 мм. Если раскладка не помещается на поле станка, программа предупредит.

При фрезеровании стеклотекстолита образуется опасная мелкая пыль. Нужны закрытая зона, аспирация с HEPA-фильтрацией и защита органов дыхания.

## Что и как считается

**Крыло** (`crates/cadplus-aero`). Консоль считается как балка, заделанная у корневой нервюры:

- Расчётная подъёмная сила `L = n · f · m · g`, на консоль — `L/2`.
- Нагрузка по размаху распределена по Шренку: среднее трапециевидного и эллиптического распределений.
- Перерезывающая сила Q и изгибающий момент M получаются интегрированием от конца консоли.
- Где проходят несколько лонжеронов, момент делится между ними пропорционально EI. Напряжение `σ = M·c/I`, запас — предел прочности / σ (коэффициент f уже в нагрузке).
- Прогиб — двойное интегрирование `M/ΣEI` от заделки. Стык лонжеронов встык считается неразрезным, об этом выводится предупреждение.
- Соединительная трубка: момент у корня консоль передаёт парой сил через крайние нервюры на трубке (приближение «две опоры»). По этой силе проверяется смятие кромки отверстия `F / (d · t)`.
- Участки без лонжерона, лонжероны, которые не помещаются в профиль, и стык без перекрытия попадают в предупреждения.

**Нервюры** (`crates/cadplus-rib`, `crates/cadplus-topopt`):

- **Контур.** Профиль масштабируется под хорду станции. Отверстие под лонжерон — на средней линии профиля, с посадкой (для ЧПУ) или допуском печати (для FDM).
- **Запретные зоны.** Полоса вдоль контура под обтяжку плёнкой и кольца вокруг отверстий всегда остаются сплошными.
- **Закрепление и нагрузка.** Нервюра закреплена по кромке отверстия под лонжерон. Нагрузка — её доля подъёмной силы, распределённая по верхнему контуру по тонкой теории профиля: `Δp ∝ √((1 − x̄)/x̄)`.
- **Оптимизация.** Метод SIMP в плоском напряжённом состоянии: фильтр плотности, обновление OC, прямой ленточный решатель Холецкого.
- **Вырезы.** Сначала отбираются элементы с плотностью ниже порога. Для ЧПУ остаются только места, куда целиком проходит фреза: морфологическое «открытие» кругом радиуса фрезы. Мелкие вырезы (меньше круга двойного диаметра фрезы) не делаются. Затем строятся контуры (марширующие квадраты), сглаживаются и упрощаются.

**Ограничения первой версии:**

- Напряжения в самих нервюрах не проверяются. Оптимизация минимизирует податливость при заданной доле материала.
- Нервюры, через которые трубка передаёт корневой момент (у корня и на 200 мм), нагружены сильнее. Оптимизация учитывает только их аэродинамическую нагрузку, смятие проверяется отдельно в расчёте крыла.
- Кручение крыла, нагрузки от элеронов и посадки не считаются.
- Узел трубки с поперечным V 2° не проектируется. Программа показывает только нагрузки, которые узел должен выдержать.

## Проверка

```
cargo test --workspace
```

| Что проверяется | Эталон |
|---|---|
| Консоль под равномерной нагрузкой: момент у корня и прогиб конца | Формулы `q s²/2` и `q s⁴/(8EI)`, точность 0,01% |
| Эллиптическая нагрузка: момент у корня | `2 L s / (3π)` |
| Сумма нагрузок на нервюры | Равна `L/2` |
| Решатель SIMP: MBB-балки 60×20 и 30×10 | Независимая реализация top88 (Andreassen и др., 2011): податливость совпадает до 10⁻⁶, число итераций то же |
| Профиль Clark Y | 11,7% толщины на 28% хорды (база UIUC) |
| Нервюры | Вырезы не заходят в кромку и кольца, щель уже фрезы закрывается, DXF содержит все детали |

## Структура кода и соответствие спецификации

| Crate | Что делает | Требования SRS |
|---|---|---|
| `cadplus-aero` | Нагрузки по размаху, эпюры, лонжероны, трубка, нагрузки на нервюры, библиотека материалов | FR-12, FR-16–FR-19 |
| `cadplus-topopt` | 2D-топооптимизация SIMP | FR-09, NFR-09 |
| `cadplus-rib` | Профиль `.dat`, геометрия и задача нервюры, ограничения изготовления, DXF/SVG | FR-03, FR-06 (DXF), FR-08, FR-11, FR-13, FR-14 |
| `cadplus-gui` | Окно, проект, отмена, фоновый расчёт | FR-02, FR-04, FR-07, FR-10, NFR-01, NFR-05 |

Чего ещё нет по сравнению со спецификацией:

- решатель в отдельном процессе с gRPC (AD-01, AD-04) — пока фоновый поток;
- контрольные точки решателя;
- импорт STEP и экспорт STL для нервюр;
- параметрический проектировщик каркаса и связь с ядром yadro.

Контур из поля плотности и экспорт DXF позже перейдут в ядро: это запланировано на его ступень 1.
